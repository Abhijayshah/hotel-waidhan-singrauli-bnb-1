## 3. Technology stack

Use the following stack:

- Framework: latest stable Next.js release compatible with the project requirements, using App Router.
- Language: TypeScript with strict mode.
- UI: React and Tailwind CSS.
- Backend: Next.js Route Handlers and server-side Node.js functionality.
- Database: Supabase PostgreSQL.
- ORM: Drizzle ORM.
- Authentication: Supabase Auth with secure server-side authorization.
- Validation: Zod for request and environment validation.
- Image management: design an integration-ready interface for Cloudinary or Cloudflare R2; do not require paid credentials during setup.
- SEO: Next.js Metadata API, canonical URLs, sitemap, robots.txt, and JSON-LD.
- Analytics: prepare integration points for Google Search Console and Google Analytics 4.
- Deployment: prepare for Vercel or another compatible Next.js host.
- Payments: leave a clean integration boundary for Razorpay in a later phase.

Use compatible, stable dependency versions. Avoid unnecessary libraries and duplicate styling systems.

## 7. SEO foundation

Prepare the project for the approved page-by-page keyword strategy.

- Set the canonical production domain centrally.
- Configure default title and description metadata.
- Establish reusable metadata helpers.
- Add a valid `robots.ts`.
- Add a `sitemap.ts` foundation that can include approved public routes as they are implemented.
- Create reusable JSON-LD utilities with valid, factual data only.
- Ensure the site name and business details can be maintained centrally.
- Do not create keyword-stuffed content, fake reviews, or unsupported amenity claims.
- Do not publish all planned routes as empty placeholder pages.
- Do not claim rankings or performance scores before measuring them.

Preserve the strategy's primary keyword assignments, including the homepage targeting "Hotel in Waidhan", the rooms hub targeting "Affordable rooms in Waidhan Singrauli", and the dedicated dormitory and PG pages targeting their respective search intents.
