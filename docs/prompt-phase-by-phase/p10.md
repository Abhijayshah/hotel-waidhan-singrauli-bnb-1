## 5. Google Analytics 4

Prepare or integrate GA4 using the measurement ID supplied by the owner.

Requirements:

- Keep the measurement ID in environment configuration.
- Do not invent a measurement ID.
- Avoid loading analytics unnecessarily when consent or applicable privacy requirements prohibit it.
- Prevent duplicate page-view events.
- Verify that client-side route navigation is tracked appropriately for the actual implementation.
- Avoid tracking private admin routes unless there is a documented, privacy-appropriate reason.

Define a clear event plan with useful events such as:

- `view_accommodation`
- `click_call`
- `click_whatsapp`
- `click_directions`
- `booking_enquiry_start`
- `booking_enquiry_submit`
- `booking_enquiry_success`
- `booking_enquiry_error`

Use valid GA4 event naming conventions and avoid unnecessary custom dimensions.

Only send `booking_enquiry_success` after the server has confirmed successful persistence. Do not send guest names, phone numbers, email addresses, messages, enquiry IDs that expose private records, or other personal information to analytics.

For phone and WhatsApp links, track the action without recording message content or personal contact details.

Prevent duplicate events caused by repeated renders, hydration, or repeated submissions.
